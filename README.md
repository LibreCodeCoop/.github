# LibreCode Coop organization configuration

This repository contains the GitHub organization configuration and automation
used by LibreCode Coop.

LibreCode Coop builds, maintains and supports free software for organizations
that need sustainable technology, open standards and control over their own
infrastructure.

- Services: https://librecode.coop/
- Organization profile: [profile/README.md](profile/README.md)

## Why this repository exists

Sustainable free software needs more than code: projects also benefit from
consistent collaboration, discoverability and long-term maintenance. This
repository maintains LibreCode Coop's shared organization profile, community
conventions and project practices, reducing duplicated setup across projects.

Maintainer documentation covers
[repository governance](docs/repository-governance.md) and
[workflow distribution](docs/cross-repository-automation.md).
